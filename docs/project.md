# Проектирование магазина «Шесть струн»

## Задача

Покупатель собирает комплект для игры на гитаре. Новичку нужно отличить электрогитару от акустической и увидеть цену комплекта с усилителем. Музыканту, который покупает расходники, важно выбрать толщину медиатора и количество упаковок.

## Требования к учебной версии

1. Каталог показывает электрогитары, акустические гитары, басы, усилители, педали и аксессуары. Фильтр категории доступен с главной страницы.
2. Карточка содержит фотографическую иллюстрацию, описание, цену, характеристики и доступные варианты.
3. Корзина объединяет одинаковые варианты, позволяет менять количество и удалять товары. После перезагрузки вкладки выбранные позиции восстанавливаются.
4. При самовывозе сбор равен нулю. Курьерская доставка стоит 500 ₽ и требует адрес. Для обоих вариантов нужны имя и электронная почта.
5. Сервер проверяет товары и рассчитывает стоимость. Учебный заказ получает номер и переходит из состояния ожидания в состояние подтверждённой демо-оплаты.
6. Покупатель может повторно открыть ссылку на квитанцию. Повтор подтверждения сохраняет прежний статус.

## Устройство приложения

Браузер отображает интерфейс на React. React Router переключает экраны, Vite обслуживает приложение в режиме разработки и собирает выпуск. Браузер хранит корзину в localStorage. Серверный обработчик одинаков для Node.js с SQLite и для размещения в Sites с D1.

| Сущность | Данные |
| --- | --- |
| Товар | Код, категория, название, цена, описание, варианты, технические характеристики |
| Позиция | Код товара, выбранный вариант, количество, цена на дату заказа |
| Заказ | Случайный идентификатор, ключ повторной отправки, контакты, доставка, состав, итог, дата создания и статус |

Для создания заказа клиент отправляет `POST /api/orders` с заголовком `Idempotency-Key`. Уникальный индекс защищает от дублирования при повторе запроса с теми же данными. Квитанция загружается по `GET /api/orders/:id`. Подтверждение выполняется через `POST /api/orders/:id/pay-demo`. Номер в ссылке даёт доступ к сумме и составу заказа. Контакты остаются в базе.

## Интерфейс и границы демонстрации

Главная страница показывает выбранную модель и каталог. Из карточки покупатель открывает боковую корзину, затем переходит на отдельные экраны оформления и оплаты. На узком экране форма и сумма заказа располагаются друг под другом. Кнопки вариантов и категорий передают состояние выбора программам экранного доступа.

Цены и фотографии иллюстрируют учебный ассортимент. Получение товара и оплата моделируются внутри приложения. Внешние платёжные и курьерские службы в этой версии не подключены.
