# Шесть струн

Учебный интернет-магазин гитар и оборудования. Каталог открыт всем. После регистрации покупатель получает личную корзину и историю заказов. React отображает магазин, Python и Django обрабатывают запросы, SQLite хранит пользователей, серверные сессии, корзины и заказы. Оплата демонстрационная.

## Запуск на компьютере или в GitHub Codespaces

Нужны Python 3.10+ и Node.js 22.13+ с npm. Из корня репозитория выполните в терминале macOS или Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm ci
npm run dev
```

Откройте [магазин](http://127.0.0.1:5173). В Codespaces откройте вкладку **Ports**, выберите порт **5173** и нажмите **Open in Browser**. При следующих запусках достаточно `npm run dev`. Команда применяет миграции, включает пересборку React и запускает сервер Django. Для другого порта задайте переменную `PORT`.

Для Windows создайте окружение командой `py -m venv .venv`, затем используйте `.venv\Scripts\python.exe -m pip install -r requirements.txt`. Команды npm те же.

## Проверка личной корзины

1. Нажмите **Войти → Создать новый аккаунт**, введите имя, email и пароль длиной от 8 символов.
2. Добавьте товар и откройте **Аккаунт → Выйти из аккаунта**.
3. Зарегистрируйте второго покупателя в том же браузере. У него будет пустая корзина.
4. Войдите снова в первый аккаунт. В корзине появится сохранённый товар.
5. Оформите заказ и подтвердите демо-оплату. Квитанция доступна владельцу в разделе **Аккаунт → Мои заказы**.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `server/settings.py` | Подключение SQLite, сессий Django и защиты форм |
| `server/models.py` | Модели CartItem и Order со ссылкой на пользователя Django |
| `server/migrations/` | Схема таблиц магазина. Таблицы пользователей и сессий создают встроенные миграции Django |
| `server/urls.py` | Маршруты сайта и API |
| `server/views.py` | Регистрация, вход, выход, изменение личной корзины, оформление и чтение заказов |
| `src/account.jsx` | Форма входа и регистрации, профиль и история заказов |
| `src/main.jsx` | Каталог, карточки, корзина и оформление |
| `src/products.json` | Общий каталог моделей и цен для клиента и сервера |
| `server/tests.py` | Проверки API, сессий, расчёта суммы и разделения данных |

## Сборка и тесты

```sh
npm test
npm run build
npm start
```

Остановите сервер разработки перед `npm start`, если он занимает тот же порт. Сам бэкенд можно запустить напрямую после сборки: `.venv/bin/python manage.py migrate` и `.venv/bin/python manage.py runserver 127.0.0.1:5173`.

SQLite-файл `data/shop.sqlite` создаётся локально. Для показа используйте вымышленные контактные данные. Старые заказы без владельца сохраняются в прежней таблице и не назначаются новым аккаунтам. Старая анонимная корзина браузера также не переносится в аккаунт. Данные, ключ Django и виртуальное окружение исключены из Git.
