# Шесть струн

Учебный магазин гитар на Python и Django. Сервер формирует страницы каталога, личной корзины и заказов по HTML-шаблонам. SQLite хранит аккаунты и покупки. Оплата демонстрационная.

## Первый запуск

Из корня проекта в терминале macOS или Linux выполните команды с Python 3.10 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 127.0.0.1:5173
```

Откройте [магазин на своём компьютере](http://127.0.0.1:5173/). При следующем запуске активируйте окружение и повторите последнюю команду. На Windows создайте окружение через `py -m venv .venv` и активируйте в PowerShell через `.\.venv\Scripts\Activate.ps1`. Остальные команды с `python` те же.

Для показа через GitHub выберите **Code → Codespaces → Create codespace on main**. В терминале выполните те же команды, заменив последнюю на `python manage.py runserver 0.0.0.0:5173`. Во вкладке **Ports** откройте порт **5173** через **Open in Browser**.

## Проверка личной корзины

1. Нажмите **Войти → Создать новый аккаунт**, введите имя, email и пароль длиной от 8 символов.
2. Добавьте товар и откройте **Аккаунт → Выйти из аккаунта**.
3. Зарегистрируйте второго покупателя в том же браузере. У него будет пустая корзина.
4. Войдите снова в первый аккаунт. В корзине появится сохранённый товар.
5. Оформите заказ и подтвердите демо-оплату. Квитанция доступна владельцу в разделе **Аккаунт → Мои заказы**.

## Где искать код

| Файл | Что показать на защите |
| --- | --- |
| `server/urls.py` | Как адрес страницы связан с функцией Python |
| `server/pages.py` | Каталог, обработка HTML-форм, выбор шаблона и переход после сохранения |
| `server/templates/` | Общая шапка в base.html и шаблоны отдельных страниц |
| `server/views.py` | Проверка email и пароля, изменение корзины, расчёт суммы и запись заказа. Здесь же находится JSON API |
| `server/models.py` | Связь CartItem и Order с пользователем через ForeignKey |
| `server/settings.py` | Подключение SQLite и сессий |
| `server/products.json` | Товары, варианты, характеристики и цены |
| `public/` | Оформление и фотографии |

После активации окружения команда `python manage.py test server` запускает проверки на отдельной базе. Для рабочего магазина Django создаёт файл `data/shop.sqlite`. Он сохраняется при перезапуске. Пользовательские данные и ключ сессий исключены из Git.
