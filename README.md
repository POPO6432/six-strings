# Шесть струн

Учебный интернет-магазин гитар и оборудования. В проекте есть витрина, карточки с характеристиками, корзина, выбор способа получения, оформление и подтверждение демонстрационной оплаты. Названия моделей, цены и ассортимент придуманы для лабораторной.

## Локальный запуск

Нужны Node.js 22.13+ с модулем `node:sqlite` и npm. Из каталога проекта выполните команды в терминале.

```sh
npm ci
npm run dev
```

Откройте [магазин](http://127.0.0.1:5173). Сервер создаст файл `data/shop.sqlite` при первом запуске. В нём хранятся заказы, в том числе контакты, которые вы ввели при оформлении. Для показа используйте вымышленные данные. Настройка ключей и отдельной базы не требуется.

## Проверка и сборка

```sh
npm test
npm run build
npm start
```

Команда `npm start` запускает собранную версию с тем же API и базой. Остановите сервер разработки перед запуском на том же порту. Порт задаётся переменной `PORT`.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/catalog.js` | Модели, цены в рублях, характеристики, доступные варианты |
| `src/main.jsx` | Витрина, карточка модели, корзина, оформление и квитанция |
| `src/cart.js` | Изменение количества и восстановление корзины |
| `server/api.js` | Валидация заказа, расчёт итогов и демо-оплата |
| `server/local.js` | Node.js и SQLite для локального запуска |
| `server/worker.js` | Обработчик запросов для размещения в Sites с D1 |
| `drizzle/0000_orders.sql` | Схема таблицы заказов |
| `tests/shop.test.js` | Автоматические проверки корзины и API |
